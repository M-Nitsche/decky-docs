## Connection issues

<AccordionGroup>
  <Accordion title="Your assistant says Decky tools are not available" icon="plug-circle-xmark">
    **Claude Desktop / Claude Code / Cursor:**

    1. Confirm the server URL is exactly `https://mcp.decky-ai.com/mcp` (no trailing slash).
    2. Check the `Authorization` header is `Bearer dk_live_YOUR_KEY` (not `Token`, not `API-Key`).
    3. Restart Claude Desktop (quit fully, reopen).
    4. In Claude Desktop, click the tools icon to inspect connected tools. If Decky isn't listed, the config file has a syntax error — validate it at [jsonlint.com](https://jsonlint.com).

    **Claude.ai web:**

    1. Go to [claude.ai/customize/connectors](https://claude.ai/customize/connectors) and check the connector is listed as connected.
    2. If it shows an error, remove it and re-add `https://mcp.decky-ai.com/mcp`.
    3. Make sure you signed in to Decky with the same account as your platform account.

    **Other MCP clients:**

    1. Confirm the server URL is exactly `https://mcp.decky-ai.com/mcp` (or `https://mcp.decky-ai.com/enterprise/mcp` for [work accounts](/authentication#enterprise)).
    2. Remove the server and add it again to sign in afresh, or check the API key header as above.
  </Accordion>

  <Accordion title="401 Unauthorized" icon="lock">
    Your API key is invalid, expired, or revoked.

    1. Go to [app.decky-ai.com](https://app.decky-ai.com) → **API Keys**.
    2. Check whether the key is listed and not revoked.
    3. If it's expired or revoked, create a new key and update your config.
    4. Keys are shown only once at creation — if you lost it, create a new one.
  </Accordion>

  <Accordion title="Your API key does not have the '…' scope" icon="shield-halved">
    Your key was created without the scope needed for the operation.

    1. Go to **API Keys** on the platform.
    2. The existing key cannot have scopes added — revoke it and create a new one with all needed scopes.
    3. The default "all scopes" option includes everything.
  </Accordion>
</AccordionGroup>

## Work account (Decky Enterprise) issues

<AccordionGroup>
  <Accordion title="Your organisation isn't set up for Decky Enterprise" icon="building">
    You signed in with a Microsoft work account from an organization that isn't set up for Decky Enterprise, or whose access is suspended. The page shows your organization's tenant ID.

    - To set up your organization, contact your Decky contact or [hello@decky-ai.com](mailto:hello@decky-ai.com) and include the tenant ID.
    - If you have a personal Decky account, connect `https://mcp.decky-ai.com/mcp` instead.
  </Accordion>

  <Accordion title="Microsoft error AADSTS50105 (user not assigned)" icon="user-lock">
    Your organization requires users to be assigned to the "Decky AI" enterprise app in Microsoft Entra ID. Ask your Entra admin to assign you, or your group, to the app.
  </Accordion>

  <Accordion title="Microsoft asks for consent or admin approval" icon="user-shield">
    Your organization hasn't approved the "Decky AI" app yet. An Entra admin of your organization grants consent once, for everyone, at:

    ```text
    https://login.microsoftonline.com/<tenant-id>/adminconsent?client_id=6502e5de-77b2-4f9b-a470-36a53aefd31c
    ```
  </Accordion>

  <Accordion title="The enterprise endpoint rejects my API key" icon="key">
    The enterprise endpoint (`https://mcp.decky-ai.com/enterprise/mcp`) only accepts a Microsoft work-account sign-in. API keys work on `https://mcp.decky-ai.com/mcp`. See [API keys for work accounts](/authentication#api-keys-for-work-accounts).
  </Accordion>

  <Accordion title="check_usage shows the Free plan on my work account" icon="coins">
    Each user of your organization needs the Enterprise plan, which Decky assigns. Until then, an account that first connects through MCP starts on the Free plan. Ask your Decky contact to assign the Enterprise plan to your account.
  </Accordion>
</AccordionGroup>

## Generation issues

<AccordionGroup>
  <Accordion title="The deck is taking a long time" icon="clock">
    Generation time scales with slide count:

    | Slides | Typical time |
    | --- | --- |
    | 5 | ~2–4 minutes |
    | 10 | ~4–8 minutes |
    | 20 | ~8–15 minutes |
    | 40 | up to ~25 minutes |

    This is expected. Your assistant polls automatically — you don't need to keep the conversation open.
  </Accordion>

  <Accordion title="Job failed" icon="triangle-exclamation">
    The `error` field on the job object explains why. Common causes:

    | Error message | Fix |
    | --- | --- |
    | `Master template not found` | The master was deleted while the job was waiting or running. Choose another master and create the deck again. |
    | `Job exceeded 15 minute limit` | The job ran too long. Retry with fewer slides. |
    | `Agent produced no slides` | Decky couldn't build any slide. Add detail to the prompt and retry. |
    | `No slide could be filled (…)` | A [`fill_templates`](/tools/fill-templates) job filled no slide; the reasons follow in brackets. Send more material (real data for chart slides) or pick other templates. |

    Decky retries a failed job once before marking it `failed`. All credits from a failed job are refunded automatically.
  </Accordion>

  <Accordion title="The download link expired" icon="link-slash">
    Download links are short-lived (a few minutes). Ask your assistant for a fresh one:

    > "Can you give me a new download link for my deck?"

    It calls [`get_deck_download_url`](/tools/get-deck-download-url) again with the same job ID.
  </Accordion>

  <Accordion title="The deck file has expired" icon="calendar-xmark">
    Deck files are stored for **30 days**, then deleted. Regenerate:

    > "Regenerate the deck about [topic] — the old one expired."
  </Accordion>

  <Accordion title="A slide was skipped or left out" icon="forward">
    For [`fill_templates`](/tools/fill-templates) jobs, [`get_deck_status`](/tools/get-deck-status#fill-templates-report) reports it in `progress.report`, and the deck card lists it under *skipped* or *left out of the storyline*:

    - `skipped`: a slide that couldn't be filled, with the reason. The most common one is `no usable chart data (…)`: the slide has a chart, and your material had no real data for it.
    - `dropped`: a slide of a library deck that Decky left out of the storyline because the material couldn't support it, with the reason.

    Skipped slides aren't charged. To get the slide, send your assistant the missing data, such as the figures behind the chart, and fill it again.
  </Accordion>

  <Accordion title="The deck has “[… — to confirm]” placeholders" icon="circle-question">
    Your material didn't give a fact the slide needs, so Decky wrote a visible placeholder instead of inventing it, such as `[€ m — to confirm]`, or `[TBC]` in short slots. `progress.report.placeholders` lists each one with its slide number, and `progress.report.gaps` lists the facts the material lacked. Replace them in PowerPoint, or send your assistant the facts and fill the slides again. See [“To confirm” placeholders](/slide-library#to-confirm-placeholders).
  </Accordion>
</AccordionGroup>

## Interactive card issues

<AccordionGroup>
  <Accordion title="The deck card stopped refreshing" icon="rotate">
    The card stops checking the job after 30 minutes, or when it can't reach Decky several times in a row, and says *Stopped refreshing*. The job itself carries on. Ask your assistant for the status:

    > "What's the status of my deck?"
  </Accordion>

  <Accordion title="The library picker says “Paste this into the chat”" icon="clipboard">
    This chat can't take your choice from the card directly. Click **Copy** and paste the text into the chat; your assistant then has Decky fill the slides you picked.
  </Accordion>
</AccordionGroup>

## Credit issues

<AccordionGroup>
  <Accordion title="Insufficient credits" icon="coins">
    You don't have enough credits in the current period. Options:

    - Ask for fewer slides: "Create a 5-slide deck instead of 10."
    - Wait until your monthly credits reset. On a monthly plan, [`check_usage`](/tools/check-usage) shows the reset date as `period_end`.
    - Upgrade to a higher plan — see [decky-ai.com/pricing](https://decky-ai.com/pricing).
  </Accordion>

  <Accordion title="Too many active jobs" icon="layer-group">
    Each account can have up to 5 queued or running jobs at once. Wait for one to finish, or cancel one:

    > "Cancel my currently running deck job."
  </Accordion>
</AccordionGroup>

## Still stuck?

<Card title="Contact support" icon="life-ring" href="mailto:support@decky-ai.com" horizontal>
  Email **support@decky-ai.com** or visit [app.decky-ai.com](https://app.decky-ai.com).
</Card>

When you reach out, include:

- The **job ID** (e.g. `3f6c2a1e-8b4d-4c7a-9e21-5d0f7b9a1c34`) if the issue is with a specific deck.
- The **error message** you saw.
- Which **client** you're using (Claude.ai web, Claude Desktop, ChatGPT, VS Code, Cursor, etc.).
