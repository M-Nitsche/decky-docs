Sign in nowDetectedEach user signs in through the server’s OAuth flow before they can use any tools or resources.

No sign-inPick this for servers with open access, or for servers that use an API key instead of OAuth.
OAuth client
Use Claude’s published identityThe server reads Claude’s client details from a URL Anthropic hosts (CIMD). Nothing to set up, but the server must support it.
Register automaticallyDetectedClaude registers OAuth clients with the server as users connect (DCR). Works with most servers, but creates many client registrations on busy ones.
Use your own OAuth clientEnter a client ID you registered with the server yourself. Leave the secret blank unless your authorization server requires one.
