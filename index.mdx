</Warning>

## What you can do

| Say something like | What happens | Cost |
| --- | --- | --- |
| "Create a 10-slide deck about our Q3 results" | Generates a complete PowerPoint deck | 10 credits / slide (1 for slides built from library templates) |
| "Make a 15-slide investor deck on climate tech" | Full deck with layout and copy | Up to 150 credits |
| "Use my company template and build a sales pitch" | Same, with your uploaded brand design | 10 credits / slide (1 for library slides) |
| "Find a board-review deck in the Decky library and fill it with these figures" | Fills a professionally designed library deck with your material | 1 credit / slide |
| "How many credits do I have left?" | Shows your balance and plan | Free |

<Note>
Generation takes a few minutes. Your AI client polls automatically — you just wait for the download link. In clients that show [interactive cards](/interactive-cards), such as claude.ai and Claude Desktop, a live deck card shows the progress, previews of the finished slides, and **Download .pptx**.
</Note>

## How it works

<Steps>
  <Step title="You describe the deck">
    Tell the assistant the topic, audience, tone, and slide count.
  </Step>
  <Step title="The assistant calls create_deck">
    Or `fill_templates`, to fill a deck or slides you picked from the [slide library](/slide-library). Credits are reserved upfront. Unused credits are always refunded.
  </Step>
  <Step title="Decky generates in the background">
    A complete PowerPoint is built slide by slide (typically a few minutes).
  </Step>
  <Step title="The assistant polls get_deck_status">
    It waits until the job status is `succeeded`.
  </Step>
  <Step title="You get a download link">
    A ready-to-open `.pptx` file, retained for 30 days.
  </Step>
</Steps>

## Connection options

| Client | Auth method | Best for |
| --- | --- | --- |
| Claude.ai web | OAuth — no API key | Quick start, non-developers |
| Claude Desktop | OAuth — no API key | Regular desktop users |
| Claude Code | API key | Developers / automation |
| Cursor | API key | Developers |
| Other MCP clients (e.g. ChatGPT, VS Code) | OAuth where the client supports it, otherwise API key | Everyday use in those clients |
| Any MCP HTTP client | API key | Custom integrations |
| Claude Team / Enterprise, Copilot Studio, ChatGPT Enterprise | OAuth with a Microsoft work account ([enterprise endpoint](/authentication#enterprise)) | Organizations with Decky Enterprise |
