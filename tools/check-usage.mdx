---
title: "check_usage"
description: "Get your credit balance for the current billing period."
---

<Info>
**Type:** Read · **Required scope:** `usage:read` · **Cost:** Free
</Info>

## Parameters

None.

## Response

<ResponseField name="plan" type="string">
  Your current plan ID (`free`, `starter`, `pro`, `max`, `enterprise`).
</ResponseField>
<ResponseField name="monthly_credits" type="integer">
  Credits allocated per month. Yearly plans also get this allowance every month.
</ResponseField>
<ResponseField name="used" type="integer">
  Credits consumed this period (settled charges only).
</ResponseField>
<ResponseField name="remaining" type="integer">
  Credits still available.
</ResponseField>
<ResponseField name="period_end" type="string | null">
  When the current billing period ends. `null` on the Free plan. On a monthly plan, this is also when credits reset. On a yearly plan, it is the end of the billing year, but credits still refresh every month.
</ResponseField>
<ResponseField name="pricing" type="string">
  What deck jobs cost, in words: slides built from scratch, slides built from a library template, and the assets Decky uses while writing a deck.
</ResponseField>

<Expandable title="Example response">
```json
{
  "plan": "pro",
  "monthly_credits": 5000,
  "used": 340,
  "remaining": 4660,
  "period_end": "2026-07-23T00:00:00Z",
  "pricing": "10 credits per generated slide, 1 per slide built from a Decky library template, plus 20 per AI-generated image, 1 per icon and 1 per web search the agent uses"
}
```
</Expandable>

<Note>
`used` reflects settled charges only. A running job has credits reserved, but those aren't counted as `used` until the job completes. See [Credits & Plans](/credits-and-plans) for full details.
</Note>
